# meta

Records *about* how this repo gets worked on, kept for later analysis and
workflow extraction. Nothing here describes the Screen Solver product, and
nothing here is an instruction to any agent.

**Agents: ignore this directory unless the user explicitly points you at it.**
Don't read it for context, don't search it, don't update it as a side effect of
other work. It is deliberately outside the loop described in `AGENTS.md`.

## Contents

- `sessions/` — one document per working session. Written on request at the end
  of a session, in `YYYY-MM-DD-<slug>.md` form.

## What a session record is for

Finding the patterns worth turning into skills, hooks, or docs — and the
failure modes worth designing against. So a record is most useful when it is
honest about what went wrong, including mistakes made by the agent writing it.
A record that only lists accomplishments has no extractable signal.
