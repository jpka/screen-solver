# Screen Solver — map moved

**This file is retired. The canonical wayfinder map is GitHub issue #1:**
https://github.com/jpka/screen-solver/issues/1

Its contents used to be the live map, and were left behind by a major redraw —
the destination is no longer a desktop app on a capture interval, tickets are no
longer local markdown, and this repo does not use a local tracker. Read the
issue, not this file.

`.scratch/solver/` is kept as **planning history**. Its `prototypes/`,
`research/` and `spec/` directories are still linked from the GitHub issues and
should not be moved or deleted. `issues/*.md` are the pre-redraw ticket files,
superseded by the GitHub issues but preserved as a record of how the decisions
were reached.
